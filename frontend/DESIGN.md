# 旅途手记前端设计说明

本次以 Taste Skill 的应用界面流程审查与设计：选择「framed-sheet」方向，把旅行规划表单作为主要工作区，将旅行图片和最近记录作为辅助内容。

- 浅灰绿页面、白色内容面、深绿色主要操作；保留项目既有中文字体与品牌色。
- 标题、正文和表单标签以清晰可读为主，删除装饰性英文、编号和重复说明。
- 桌面采用对齐的表单与旅行图片双栏；窄屏优先展示表单，图片与历史记录依次排列。
- 结果页以日期、预算、地图和每日行程为真实内容；费用与天气仍明确标注估算和缺失状态。
- 保留可访问的字段标签、错误摘要、键盘焦点与减少动画设置；生成等待不展示虚构进度。
- 图片为本地 AI 生成的氛围图，并明确说明并非真实景点。

- 参考 Magic UI 的 Border Beam 与 Blur Fade，在 Vue 中适配柔和的边框流光与入场效果；遵循系统减少动画设置。
- 桌面图片与表单等高，结果页地图随内容区域伸展，避免无意义的大面积留白。
- 桌面首页使用紧凑表单、较宽的填写区和可伸展图片，尽量在常见屏幕高度内展示主操作；窄屏与长内容保留自然滚动。
